## 1. 议题总表（已关心 / 已处理）

**A. 定时与同步**
- 抽样相位：16 相位扫描器（A16）/ 能量定相 + 连续滑窗（Csq v3b）；相位 latch + ALIGN_GATE
  （早锁错失修复）；
- 帧到达检测：`preamble_detect`（归一化延迟自相关、DEC=8 下采样、噪声底 CFAR 跟踪、
  γ/CONF_CNT 运行期可配）；
- 定界：`sfd_detect`（64 片相干模板）；SFD 与 frame_start 语义分离；
- 抖动手性：pd 段抖动 × 成功率边界扫描；restart 语义与"攒窗"错配的治理；
- 架构对比：A16 / Csq / B8 / 共享延迟线 ref 四版本并存（`rtl/README.md`）。

**B. 频率与相位**
- CFO 估计：FFT 粗估 + 前导差分精估；检测判据改复相关模（对 CFO 免疫）；
- 消旋：`cfo_rot`（24bit 相位累加 + LUT）；残余容限实测（δ≤2 kHz 无损、10 kHz 仍 65%）；
- 旋性管理：A/B 双通道参数、上层发现/记忆/匹配/淘汰（`docs/12/15/16`）。

**C. 幅度与定标**
- 定点重规划 21→16 bit（全链口径）；ADC 12bit 量化假设验证；
- **BFP8 前导缓冲**：1024 环 + 块浮点（存储 −84%、保真 41.7 dB、BLK 旋钮 16/64/128 已验证）；
- 6 dB 档门限问题 → 噪声底 CFAR + γ/CONF 参数自适应（低档已收益：17→45）。

**D. 帧处理**：非相干解扩（|·|²，对载波相位不敏感）、PN9、CRC-16/FCS、PHR/PSDU 解帧。

**E. 损伤建模与容限（模型侧全量）**：AWGN / CFO / SFO / 定时 / 多径 / DC / IQ / 镜像 / 量化；
校正算法：CFO 两级、DC/IQ 联合 LS、MMSE 均衡。

**F. 架构与接口**：共享前端 + 双执行段（`rx_dual`）；观测集（events / CFO 估计序列 / 成败）；
pbuf 上行（BFP8）；外部参数通道；观测器（DPI-C 在线）；转储口（待定，notes §37）。

**G. 验证**：cocotb bit-true（单元/链级）+ VCS 系统级（`rx_dual_mc`）+ 边界回归 + MC +
眼图/星座/EVM + VCD/netlist 图集。

## 2. 同步器版本策略：为什么默认是 A16

- **事实**：默认编译链（`tb/rx_dual_mc/run_dual_mc.py` SOURCES 与 `rx_frontend` 例化）指向
  `preamble_sync.sv`（A16）；**Csq v3b 是 drop-in 候选文件**（同名同端口，编译期替换）。
- **"未切换" ≠ "否决"**：项目对替换的既定原则是"改动仅限新文件、可退回"（notes §30-33）；
  Csq 转正属**显式切换动作**，尚未执行。边界回归打平（edge 94=94 等）已达成，是转正的
  **必要非充分**条件。
- **保持 A16 的理由**：① 历史回归/长尾实验数量以 A16 口径积累最厚（切换有"口径重置"成本）；
  ② Csq 的验证面目前覆盖近期数轮边界回归，尚未经历同等长尾；③ 面积收益（−23%+）是
  转正评估的**动机**，不是自动理由。
- **转正清单（建议）**：SOURCES/例化切换 → `build_variants` + 全边界回归 + edge/注入 +
  关键 MC 复跑 → 数据对比定 tag。**可以先做一轮"影子对比"（同流双跑）再定**。

## 4. AWGN 数字注入模块（已实现：`rtl/common/awgn_gen.sv`）

**定位**：**测试/标定基础设施**（非功能数据通路）——与"离线生成含噪波形"并存，
提供**在线改 SNR** 的能力：回归免重生成、门限（γ/CFAR）标定、片上 BER 环回。

**方法（推荐 A）**：
- **A. 多路均匀求和（CLT）**：N 路独立均匀样（LFSR 抽头或复用 `pn9_whiten` 核的变体）
  求和 → 近似高斯（N=12–16 时峰度足够）；**移位定标** σ；I/Q 两路独立。硬件极省
  （N 个加法 + 2 个 LFSR）。
- B. Box-Muller / Ziggurat：需要 log/sqrt/查表——昂贵，不推荐首版。

**接口草案**：

```systemverilog
module awgn_gen #(parameter W = 16, parameter N = 12) (
    input  wire                 clk, rst_n, en,
    input  wire [7:0]           cfg_sigma_num,     // σ = NUM / 2^SHIFT；0 = 关闭
    input  wire [4:0]           cfg_sigma_shift,
    output wire signed [W-1:0]  out_i,
    output wire signed [W-1:0]  out_q,
    output wire                 out_dv
);
```

**注入点**：ADC 后 / MF 前（tb 一处开关：`+AWGN=<σ>`——0=用离线 mem；>0=mem 用无噪 +
在线注入）。**面积估计**：几百 cells（远小于 pbuf v2 的 635）。**验证计划**：输出直方图/
自相关白性/谱平坦度 → 与离线噪声的 BER 对齐（同 σ）→ γ 标定复现。

**外部实践参考（检索，2026-10-02）**：
- **CLT（N 路均匀求和）** 是 FPGA 实践的轻量主流（N≥12 的"近高斯"为通行工程结论）；
- 学术高精度路线 = **Box-Muller**（Lee et al., IEEE Trans. Computers 2006：两路 16bit/周期、
  误差 ≤1 ulp 并有解析误差分析；Virtex-4 实测 **1452 slices + 3 BRAM + 12 DSP**——目标为
  10^-12 级 BER 仿真）——对本项目**过重**；Ziggurat/Wallace 居中；早期 LFSR+查表法被该文
  评为"吞吐低（几十 kbps）且质量差"；
- **Xilinx 有商用 AWGN IP**（需求成熟度的旁证）；
- 结论（**按质量需求分级选型**）：本项目只需"统计匹配离线 AWGN"（方差/白性/4σ 内近似，
  服务 BER 1e-3 级）→ **CLT 首版**。

**实现与验证（2026-10-02，模块级完成）**：
- 结构：CLT N=12×5bit；64bit LFSR×2；**每拍 60 位并行滑窗 XOR**（免递归、零重叠）；
  2 级流水；σ 运行期可调（cfg_mul/cfg_shift）；
- 实测（`tb/awgn_gen`，cocotb 2/2）：σ=31.88/32、峰度 2.88、白性与 I/Q 独立性通过、
  σ 可调 8.05；**面积 424 cells**；产物 `model/out/awgn/awgn_stats.png`；
- **下一步**：dual_mc `+AWGN` 接入 + 离线噪声 BER 对齐。
