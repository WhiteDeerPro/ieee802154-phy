# 非理想效应、星座图诊断与接收机对策（v1.0）

> 日期：2026-09-25
> 定位：把"模拟/射频非理想效应"这张经典病理表翻译到本项目（802.15.4 O-QPSK，
> 零中频复基带，16 进制非相干 |·| 检测）的语境下，并决定哪些进参考模型、哪些做先验假设。

---

## 1. 如何理解星座图这张"病理表"

星座图本质是**采样信号在 I/Q 平面的散点云——整条模拟+信道链路对信号施加的
所有变换的几何成像**。诊断方法论分两步：

1. **静态几何**：点云整体怎么了？平移 → 加性偏置（DC）；剪切/平行四边形 →
   I/Q 不正交；压扁/拉长 → I/Q 增益不等；外圈内陷 → 增益压缩（AM-AM）；
   镜像点 → I/Q 不平衡的共轭镜像项。
2. **动态演变**：点云随时间怎么动？**绕原点匀速旋转 → CFO**（旋转角随采样序号
   线性增长：θ[n] = 2πΔf·n/fs——你问的"频偏造成星座逐渐旋转"完全正确，
   原始采样点上 CFO 把星座拉成圆环）；绕原点随机游走 → 相位噪声；
   沿径向呼吸/漂移 → AGC、1/f、热效应。

非理想效应按来源分两类：
- **模拟前端类**（DC/LO 泄漏、I/Q 不平衡、相位噪声、1/f、偶次失真、非线性）：
  发生在 LNA/混频器/VCO/PA；
- **信道与频率参考类**（CFO、定时偏差、多径）：发生在空中接口与收发晶振频率差。

## 2. 本项目的两道过滤（为什么别人的表不能直接搬）

**过滤 1 —— 我们的"星座"不是 QPSK 四点。** O-QPSK 半正弦成形下，码片级星座是
I/Q 两轨 BPSK（点在坐标轴上），符号级是 16 进制；诊断时看点云在轴上的聚集质量，
而不是四个象限点。

**过滤 2 —— 非相干 |·| 检测的免疫谱。** 判决只依赖"与 16 个 PN 模板相关的幅值"，
因此：
- **窗内近似恒定的相位过程全部免疫**（信道静态相位、慢相位噪声的大部分、
  AM-PM 的静态分量）；
- **破坏 I/Q 两轨正交性或幅度关系的前端损伤不免疫**（I/Q 不平衡、DC 偏移）；
- **在 16 µs 积分窗内随时间变化的过程不免疫**（CFO、快相位噪声、码内定时漂移）。

还有一个容易被忽视的红利：**半正弦 O-QPSK = 恒包络（MSK 性质）**——发射信号
幅度恒定，对 PA 的 AM-AM 增益压缩天然免疫，这是它相对 16QAM/OFDM 的体质优势。

## 3. 汇总大表

| 非理想效应 | 物理机理 | 星座图表现 | 对本项目（非相干|·|）的实际影响 | 基带对策 | 本项目处置 |
|---|---|---|---|---|---|
| DC 偏移 / LO 泄漏 | 自混频，LPNA 直流 | 点云整体平移离原点 | 每轨软值带偏置；与 PN 序列的和相关 → 各假设固定偏置 → 阈值效应 | 前导码期信号均值为零 → 直接取均值估计并扣除 | **Feature 2：已实现（联合 LS 校正，BER 回基线）** |
| I/Q 幅度不平衡 | I/Q 通道增益不等 | 点云矩形化（压扁/拉长） | 两轨 SNR 不均；小幅值检测损失 | 前导码期按轨能量归一 | **Feature 2：已实现（打包一并估计）** |
| I/Q 相位不平衡 | LO 非正交（≠90°） | 平行四边形/倾斜 | 跨轨泄漏 → 相关噪声底抬高 | 2×2 矩阵校正 | **Feature 2：已实现（打包一并估计）** |
| 综合 I/Q 不平衡 | 上三项复合 | 镜像点、点云分裂 | 等效 α·s+β·s\* 仿射模型 | 联合 LS：α、β、DC 一次估出 | 同上 |
| CFO | 收发晶振频率差 | **星座随时间匀速旋转成环** | 解扩固有容忍 ~20 kHz；同步相关器 5 kHz 即崩 | 两级估计：网格粗搜 + 相关峰相位差精估，数字混频纠正 | **Feature 1：已实现（残差 0.34 kHz ≤ 7 kHz）** |
| 相位噪声 | LO 相位抖动 | 绕原点弧状扩散 | 16 µs 窗内积分相位噪声 ~1° 级 → \|·\| 基本吸收 | 无需专门对策 | 先验假设：可忽略（数值佐证 §5） |
| 1/f 噪声 | 低频闪烁 | 中心附近模糊拉长 | 被 DC 估计旁路吸收；高通可抑 | 与 DC 校正合并 | 视为理想（由 DC 估计顺带覆盖） |
| 偶次失真 | 平方项 → 低频/DC | DC 漂移、低频波动 | 同 DC 类 | 同 DC 校正 | 视为理想（由 DC 估计顺带覆盖） |
| ADC/DAC 量化 | 均匀 mid-tread 舍入 | 点云栅格化（高 SNR 才可见） | 量化噪声功率 Δ²/12，确定性可精确建模（非随机损伤） | 位宽扫描：4b 全工作点退化 <0.1 dB（量化 SNR 22.8 dB ≫ 工作点噪声） | **已建模：`model/experiments/run_quant.py` 位宽扫描** |
| 非线性（AM-AM/AM-PM） | PA 增益压缩/相移 | 外圈点内压 | **恒包络 O-QPSK 对 AM-AM 天然免疫**；AM-PM 静态分量被 \|·\| 吸收 | 无需专门对策 | 先验假设：不建模（恒包络红利） |
| 定时偏差 | 采样相位偏移 | 点云向原点径向收缩 + 轴向弥散（ISI） | 静态 ±0.5 码片内平坦（实测） | 早迟门/插值跟踪；短包内漂移忽略 | 已建模；SFO 实测：短帧(20B)±40ppm 零退化，长帧(127B)±40ppm BER 退化 ~2 数量级 → 跟踪环对长帧必要 |
| 多径 | 多抽头叠加 | 静态旋转 + 不对称弥散 | DSSS 处理增益硬扛（≤1 码片扩展实测可容忍） | 无需均衡（RAKE 可选增强） | 已建模；先验：延迟扩展 ≤1 码片 |

## 4. 选取的 3 个 Feature（其余 = 先验假设）

| Feature | 入选理由 | 算法机制（参考模型介入点） |
|---|---|---|
| **1. CFO**（已实现：残差 0.34 kHz） | 同步崩塌点 5 kHz ≪ 双端 ±20 ppm ≈ 96 kHz 实际频偏，不估就失联 | 网格粗搜（±300 kHz/10 kHz 步进，最大化前导相关峰）+ 峰相位差精估；数字混频纠正；目标残差 ≤7 kHz |
| **2. DC 偏移 + I/Q 不平衡**（打包，已实现） | 零中频架构的经典病灶，破坏两轨正交/幅度——正好是非相干检测不免疫的两类 | 前导码期（256 码片发送信号已知且零均值）联合 LS：r = α·s + β·conj(s) + d 一次估出 α、β、d，接收全程应用逆变换 |
| **3. 多径**（沿用已有模型） | 室内场景无法回避 | 无新算法：处理增益硬扛；先验：延迟扩展 ≤1 码片（等幅双径频谱凹陷场景已实测通过） |

**先验假设（视为理想，记录在案）：** 相位噪声（16 µs 窗内 ~1° rms，|·| 吸收，
留数值佐证任务）；1/f 与偶次失真（被 DC/前端估计顺带覆盖）；PA 非线性
（恒包络免疫 + |·| 吸收静态 AM-PM）；定时跟踪（assisted 同步 + 短包漂移忽略——SFO 实测边界：
短帧 20B@±40ppm 零退化，长帧 127B@±40ppm 帧尾漂移 0.35 码片、BER 退化 ~2 数量级，
跟踪环列为 Phase 2 增强）；**收发相对运动（多普勒）先验视为 0**——低速场景
为 Hz 级，超音速级（1000 m/s ≈ 8 kHz）仍在晶振先验界 ±96 kHz 内被同一 CFO
估计器吸收，帧内漂移（100 g ≈ 33 Hz/4.25 ms）可忽略，不单独建模。
