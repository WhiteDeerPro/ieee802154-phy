# 23. despreader 演进：度量变体与基线切换（2026-10-04）

> 背景、变体谱系、关键实验与基线决定。实验原始记录见
> `model/out/dual_mc/rtl_area_notes.md` §66 / §70–§76 与 `model/out/dual_mc/oct8_phase/`；
> 变体文件见 `rtl/rx/variants/README.md`。

## 1. 动机

非相干解扩的判决需要比较 16 路复相关值的"幅度"。原实现 `|s|² = I² + Q²`
需要 32 个 17×17 乘法器（占单模块门级 77,833 cells 的大头）。
主线思路：**判决只依赖"序"，不依赖"值"** —— 用保序近似替代精确度量，
再用串行化把"每片并行"改成"每符号一次"。

## 2. 变体谱系与资源

| 方案 | 结构 | 门级 cells（yosys synth 口径） | 判决影响 |
|---|---|---|---|
| 原版 | I²+Q²，32 乘法器 | 77,833 | — |
| 8 边形 | max/移位/加法（15/16, 15/32） | 20,191 | 单元 bit-exact；200 帧零差 |
| 8 边形 + 流水判决树 | 4 级 16→8→4→2→1（参考 `ip/mcdf`） | 20,759 | 同上（延迟 3 拍；组合路径 −65%） |
| 四边形 | max(\|I\|,\|Q\|) | 15,045 | 相位陷阱（见 §3.2） |
| **TDM（现役）** | PN 列重排 + 4 拍×4 路串行判决 | **12,016 (MODE=2) / 13,227 (MODE=1)** | 单元 bit-exact；回归全过 |
| TDM（旧版） | 平方/argmax 时分复用 | 26,776 | 逐符号一致 |

全链（csq + 原版 → TDM）：**364,749 → 233,593 cells（−36%）**（`tb/rtl_lab/synth_stats.py`）。

## 3. 关键实验

1. **单元 bit-exact**：文件回放压力台（15 万符号级）RTL 与模型统计逐项一致；
   TDM 版判决与组合版逐符号一致（含真实 12/4 片节奏）。
2. **相位**（RTL 精扫，5 万/点）：四边形 × 八边形交叉区 **15–17.5°**；
   四边形在 φ=45° 崩至八边形的 1.89×（"相位陷阱"）；八边形全相位跨度 14.3%
   （最差 φ=0°、最优 37.5°）。
3. **整链传导**：五场景 + 200 帧——八边形全程零差；
   **四边形在 snr6 出现 −1/200**（57 vs 58；字节流 4/60 帧差异）——
   "传导因子"实证：**低 SNR 边缘 × 四边形相位敏感**。
4. **真实片节奏**：`deinterleave` 输出为 **12/4 拍交替**（偶片→奇片 12 拍、奇→偶 4 拍；
   片 31→片 0 恒 4 拍）——TDM 扫描窗口据此定为 4 拍。
   （首版按"均匀 8 拍"设计，单元 tb 通过但整链 0/60——教训见 notes §74。）

## 4. 基线切换（2026-10-04）

- 主构建 `simv_ps_csq` = csq 同步器 + `+define+DESP_OCT8_TDM +DESP_QUAD`（TDM + 四边形）；
- 验证：**全回归 ALL PASS**（注入边界 8/8、edge 94/140、主流量全部持平）；
- 实测代价：200 帧 snr6 −1（57/58），s20 零差；60 帧判据场景全部持平；
- **换档/回滚**：`tb/rx_dual_mc/build_variants.py` 去掉 `+DESP_QUAD`
  → TDM + 八边形（+约 2.4k 全链 cells，200 帧零代价）。
- 旧基线重建：去掉两个 define 与 `extra_srcs`（见 build_variants.py 注释）。
