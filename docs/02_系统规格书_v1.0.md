## 1. 系统定位

单芯片 802.15.4 2.4 GHz 收发的**数字基带部分**：完成比特流与复基带 I/Q 采样流之间的全部数字处理（TX：组帧/扰码/DSSS 扩频/O-QPSK 调制/半正弦成形；RX：匹配滤波/解扩/解调/同步/去扰/解帧）。模拟射频前端、ADC/DAC 为协作边界，本规格只定义与其的接口。

## 3. PHY 帧格式（PPDU）

```
┌─────────────┬────────┬────────┬──────────┬─────────┐
│  Preamble     │  SFD   │  Frame │  PSDU     │  FCS    │
│  4 B 全 0     │ 1 B    │ Length │ (0–127 B) │ CRC-16  │
│  (8 个 0 符号) │ 0xA7   │ 1 B    │  含 MHR+  │ (ITU-T  │
│              │        │        │  payload  │ CRC-16) │
└─────────────┴────────┴────────┴──────────┴─────────┘
     SHR (5 B) ─────────┘    PHR (1 B) ───┘      ← PHY 层处理到 PHR；PSDU 之上属 MAC，透传
```

- PHR 与 PSDU 字节做数据白化（whitening），生成多项式 **x⁹ + x⁵ + 1（PN9），种子全 1**；SHR（前导 + SFD）不白化（已对照标准 §6.5.3.3 转正，`rtl/common/pn9_whiten.sv` bit-true 回归通过）；
- 接收方 CRC 校验通过后向 MAC 层上报「帧有效」。

## 4. TX 数字链路

```
MAC 字节流 → [FCS 生成] → 组帧(PHR/PSDU) → 白化(PN9)
→ 字节→符号→4bit→32chip 查表扩频(16 张 PN 序列表)
→ O-QPSK：奇码片→I 路、偶码片→Q 路，Q 路延迟半码片
→ 半正弦成形(FIR, 每码片 8 采样 @16 MHz) → I/Q 数字中频 → DAC
```

关键设计点：
- **扩频表**：16 个 32 位 PN 序列（标准 Table 73/74），综合后映射为 LUT（BRAM 或组合逻辑，视资源）；
- **成形滤波**：半正弦 h(t)=sin(πt/2T_c)，0≤t≤2T_c，滚降天然、邻道泄漏小；16 MHz 采样率下每码片 8 点，可用预存系数 FIR 或直接 CORDIC/查表「定点化时定案」；
- 码片时钟 2 MHz 由 16 MHz 主时钟整数分频，无需分数分频。

## 5. RX 数字链路

```
ADC I/Q (@16 Msps, 假设 4–6 bit) → 数字增益/直流消除(可选)
→ 匹配滤波(与 TX 成形滤波器共轭匹配)
→ 包检测：能量检测 + 前导码码片级自相关（非相干，容忍大频偏）
→ SFD 相关检测（码片级互相关，定帧边界）
→ 频偏估计与纠正（前导码相位差分 / 基于码片过采样的相关峰漂移）
→ 解扩：每符号滑动窗与 16 个 PN 序列相关，取最大者 → 4 bit 符号
→ 符号→字节 → 去白化(PN9) → PHR 解析 → PSDU → CRC 校验 → 输出字节流 + 状态/中断
```

关键设计点：
- 标准允许**非相干接收**（码片相关不需要载波相位恢复），这是 802.15.4 对数字实现最友好的特性——频率同步只做 CFO 估计纠偏到相关窗口内即可，无需 Costas 环；
- 接收机结构参考 gr-ieee802-15-4（Schmid/Bloessl 的非相干相关接收）与 UCB baseband-modem（时钟数据恢复 + 匹配滤波架构）的公开文档描述；
- 定时恢复：码片 8 倍过采样 + 相关峰插值/早迟门二选一「定点化时定案」。

## 6. 数字设计参数（初版）

| 项目 | 取值 | 说明 |
|---|---|---|
| 主时钟 | 16 MHz | 码片 8× 过采样；也符合商用芯片（CC2530 系）惯例 |
| ADC/DAC 采样率 | 16 Msps I/Q（复基带，零中频）「假设」 | 与 UCB baseband-modem 的 32 MHz ADC 时钟方案不同——那是 802.15.4+BLE 双模且有更高过采样需求；单模 802.15.4 用 16 MHz 足够 |
| ADC/DAC 位宽 | 4 bit（已扫描验证：全工作点退化 <0.1 dB，`model/experiments/run_quant.py`） | 配合 AGC/数字增益；量化 SNR ≈ 22.8 dB vs 工作点采样噪声 ≈ 2 dB，余量 ~20 dB |
| 数据通路接口 | AXI-Stream（帧数据）+ APB/寄存器（控制） | 寄存器图参考 UCB 项目文档风格（控制、状态、中断、RSSI、调谐位） |
| 复位/时钟域 | 单时钟域起步；睡眠唤醒低功耗为 Phase 3 课题 | |

## 7. 损伤模型清单（用于算法建模与验证环境）

Python 黄金模型必须支持注入以下损伤，RX 设计要求逐级对抗：

| 损伤 | 建模方式 | RX 对策 |
|---|---|---|
| AWGN | 按 Eb/N0 加噪 | 扩频增益 + 相关接收 |
| CFO（晶振 ±20 ppm 级） | 复指数旋转 | 前导码估计 + 数字混频纠正 |
| 采样定时偏差 | 分数延迟滤波器 | 过采样 + 定时恢复 |
| 多径（室内，5–10 tap）| TDL 抽头模型 | 扩频自身抗多径 + RAKE「可选」 |
| IQ 不平衡/直流偏移 | 增益/相位失衡 + DC 偏置 | 前导码估计的 DC 消除「可选」 |
| 窄带干扰（Wi-Fi 同频段） | 单音/宽带阻塞 | 扩频增益硬抗 + 干扰检测上报「可选」 |
