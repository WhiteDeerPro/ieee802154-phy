================================================================================
  CFO CORRECTION ARCHITECTURE - IEEE 802.15.4 (Zigbee) RX BASEBAND
================================================================================

PROBLEM: Carrier Frequency Offset (CFO) from crystal mismatch
- Spec: ±40 ppm worst-case → ±96 kHz @ 2.45 GHz carrier  
- Manifests as: Phase rotation 2π·Δf·t in baseband
- Critical impact: Preamble (128 µs) rotates 12.8 turns @ 96 kHz
  → Coherent correlation peak COLLAPSES → Sync FAILS

================================================================================
  TWO-BLOCK SOLUTION: Estimate Once + Correct Continuously
================================================================================

┌─────────────────────────────────────────────────────────────────────────┐
│  BLOCK 1: cfo_est.sv — Joint Estimation (Once per Frame)                │
│  Cost: ~8K complex MAC, amortized 4 MAC/sample for 20-byte packet       │
└─────────────────────────────────────────────────────────────────────────┘

Input: i_in[20:0], q_in[20:0] (matched filter output, 16 MHz)
       start (trigger from preamble_sync or external AGC)

┌───────────────────────────────────────────────────────────────┐
│  Stage 1: COLLECT (2048 cycles)                               │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  │
│                                                                │
│  For each of 8 candidate alignments p ∈ [0,7]:                │
│                                                                │
│  ┌──────────────────────────────────────────────────────┐    │
│  │  1. Sample chips at alignment p:                     │    │
│  │     v[m] = mf[p + m·SPS + offset[m]]  (256 chips)   │    │
│  │                                                       │    │
│  │  2. Remove known modulation (divide by ideal ref):   │    │
│  │     z[m] = v[m] / c_ref[m]                          │    │
│  │     → z[m] = pure phase (CFO-induced rotation)      │    │
│  │     ★ TRICK 1: Removes ±18.09° ISI from pulse shape │    │
│  │                                                       │    │
│  │  3. Differential phase (span=2 chips, same rail):    │    │
│  │     d[m] = z[m+2] · conj(z[m])                      │    │
│  │     → phase of d[m] = 2π·Δf·1µs (constant if aligned)│   │
│  │     ★ TRICK 2: I→I or Q→Q = constant 16-sample gap  │    │
│  │                                                       │    │
│  │  4. Accumulate:                                      │    │
│  │     acc[p] = Σ d[m]  (126 terms, m=2..254, step=2)  │    │
│  │     am[p]  = Σ |d[m]|₁ (L1 norm, for Q metric)      │    │
│  └──────────────────────────────────────────────────────┘    │
│                                                                │
│  Output: acc[0..7], am[0..7] (48-bit accumulators)            │
└────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│  Stage 2: CMP (1 cycle)                                       │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  │
│                                                                │
│  Phase consistency metric (CFO-blind quality):                │
│     Q[p] = |acc[p]|₁ / am[p]                                  │
│            ^^^^^^^^   ^^^^^^                                   │
│            |Σd|        Σ|d|                                    │
│                                                                │
│  Aligned correctly  → all d[m] in phase → Q ≈ 1              │
│  Aligned wrong      → random phases     → Q ≈ 1/√126 = 0.09  │
│                                                                │
│  Pick: p_hat = argmax(Q[0..7])                                │
│        ★ TRICK 3: Quality check — est_ok = (Q[p_hat] ≥ 0.25) │
│                                                                │
└────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│  Stage 3: CORDA (26 cycles) — CORDIC atan2                   │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  │
│                                                                │
│  Frequency estimate:                                           │
│     φ = arg(acc[p_hat]) = arg(Σ d[m])                        │
│     f_hat = φ / (2π · 1µs)  (differential span = 1 µs)        │
│     phase_inc = f_hat / FS  (per-sample increment)            │
│                                                                │
│  Unambiguous range: ±500 kHz (Nyquist of 1 µs diff)          │
│  Measured accuracy: bias = -2.8 kHz, σ = 8.4 kHz @ SNR=-1dB  │
│                                                                │
└────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│  Stage 4: CORDB (26 cycles) — CORDIC atan2                   │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  │
│                                                                │
│  Initial phase φ₀ (for derotation reference alignment):       │
│     φ₀ = arg(Σ z[m]) - 124·phase_inc                         │
│          ^^^^^^^^^^^   ^^^^^^^^^^^^^^^^                        │
│          center phase  correction to frame start              │
│                                                                │
│  Output: phase_off = φ₀ (loaded to cfo_rot on frame start)    │
│                                                                │
└────────────────────────────────────────────────────────────────┘

Outputs: 
  p_hat [2:0]           — Alignment point (chip phase 0-7)
  phase_inc [23:0]      — Phase increment per sample (2π full scale)
  phase_off [23:0]      — Initial phase at frame start
  est_ok                — Quality flag (Q ≥ 0.25)
  done (single pulse)   — Estimation complete

Total latency: 2048 + 1 + 26 + 26 = 2101 cycles @ 16 MHz = 131 µs


┌─────────────────────────────────────────────────────────────────────────┐
│  BLOCK 2: cfo_rot.sv — Derotation (Continuous, Per-Sample)              │
│  Cost: 1 complex multiply per sample = 4 real mults + 2 adds            │
└─────────────────────────────────────────────────────────────────────────┘

Input: i_in[20:0], q_in[20:0] (matched filter output stream)
       phase_inc[23:0], phase_off[23:0] (from cfo_est)
       load (pulse to reset phase accumulator at frame start)

┌───────────────────────────────────────────────────────────────┐
│  Algorithm: out[n] = in[n] · exp(-j·n·phase_inc)             │
│                                                                │
│  ┌────────────────────────────────────────────────────────┐  │
│  │  Phase accumulator:                                     │  │
│  │    pacc[n] = pacc[n-1] + phase_inc  (24-bit, wraps)   │  │
│  │    On load: pacc ← -phase_off (align to reference)    │  │
│  │                                                         │  │
│  │  LUT lookup (256 entries):                             │  │
│  │    idx = pacc[23:16]  (upper 8 bits)                  │  │
│  │    cos_val = COS_LUT[idx]  (16-bit)                   │  │
│  │    sin_val = SIN_LUT[idx]  (16-bit)                   │  │
│  │    → exp(-j·phase) = cos - j·sin                      │  │
│  │                                                         │  │
│  │  Complex multiply:                                      │  │
│  │    i_out = (i_in · cos + q_in · sin) >> 15            │  │
│  │    q_out = (q_in · cos - i_in · sin) >> 15            │  │
│  │                                                         │  │
│  │  ★ Why LUT + accumulator (not recursive rotation)?    │  │
│  │    - Same cost as w[n]=w[n-1]·exp(-jθ) per sample    │  │
│  │    - BUT: No error accumulation (LUT is constant)     │  │
│  │    - Phase quantization: 2π/256 = 1.4° << CFO phase  │  │
│  └────────────────────────────────────────────────────────┘  │
│                                                                │
└────────────────────────────────────────────────────────────────┘

Output: i_out[20:0], q_out[20:0] (derotated, ready for despreader)
        dv_out (data valid, delayed by 1 cycle)

Latency: 1 cycle (pipelined multiply)
Power: ~40 nJ per sample @ 16 MHz (estimated)

================================================================================
  DIAGNOSTIC EXTENSION (cfo_est_diag.sv) — NEW
================================================================================

Additional outputs for debugging and monitoring:

Q_cand[0:7] [15:0]      — Phase consistency for all candidates
                          High Q (>0.6) → candidate aligned
                          All Q < 0.25 → noise/no preamble

peak_mag2_raw [31:0]    — Correlation peak before CFO correction
peak_mag2_corrected     — After correction (should be higher)
                          Ratio measures correction effectiveness

p_second [2:0]          — Runner-up candidate alignment
Q_second [15:0]         — Quality of second-best
                          Q_best ≈ Q_second → multipath suspected

high_confidence         — (Q_best - Q_second) > 0.3
multipath_flag          — Multiple candidates have high Q
                          → Two+ strong paths detected

Use cases:
  ✓ Debug sync failures (check Q values, multipath flag)
  ✓ Monitor crystal drift (log phase_inc over time/temperature)
  ✓ Assess channel quality (peak magnitudes → SNR estimate)

Parameter: ENABLE_DIAG = 0 → all diagnostics disabled (zero area cost)

================================================================================
  KEY TAKEAWAYS
================================================================================

1. CFO is THE dominant impairment — not because it breaks despreading
   (it doesn't, we're non-coherent), but because it collapses the
   coherent preamble correlation peak.

2. Joint estimation (alignment + frequency together) breaks the
   circular dependency deadlock (need timing to estimate frequency,
   need frequency to get timing).

3. Three tricks are critical: ISI removal, span-2 differential,
   quality check. All learned from 踩坑 (debugging failures).

4. Solution is cheap and one-shot: ~8K MAC once per frame + 1 complex
   multiply per sample. No loops, no warmup, no FFT.

5. Performance: 59-65× BER improvement @ 50-96 kHz CFO. Works to 450 kHz
   (4.7× crystal spec). Residual error (±8 kHz) << tolerance (62.5 kHz).

**Bottom line: CFO correction is MANDATORY for this receiver architecture.**
**The implemented solution is optimal for the constraints (short packets,**
**non-coherent despreading, ±96 kHz spec, one-shot acquisition).**
