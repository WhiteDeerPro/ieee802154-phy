## 2. 性能基线（改动后不得低于此）

**MC 三流**（RTL，逐帧 FRMA fcs=1）：

| 用例 | 基线 | 说明 |
|---|---|---|
| snr6（dev1@6dB, 60 帧） | **17/60** | 低 SNR 灵敏度界（门限受限，非解调） |
| snr20（dev1@20dB, 60 帧） | **56/60**（稳态 56/56=100%，前 4 帧启动瞬态） | 高 SNR 正常 |
| mixdev1（4 设备×3 档, 200 帧） | **78/200**（dev1 49、dev4 29） | 多设备混合 |
| 随机流（种子 101/202/303） | 2 / 3 / 1 帧（±1 容许，见 §4） | 随机参数边缘用例 |

**矩阵（dual, dev1+dev2×4 档 SNR, 各 30 帧）**（notes §16）：

| 配置 | 6dB | 9dB | 12dB | 20dB |
|---|---|---|---|---|
| base（γ=.66,C=2） | 11 | 23 | 30 | 30 |
| g13c6（γ=.41,C=6） | 28 | 30 | 28 | 29 |

**位宽对照**（notes §8）：W=14/16/21 三档结果逐项一致（无损）。

**虚警（纯噪声 250 ms）**：假锁定 0、假定界 0、假帧 0。

## 3. 资源基线（yosys 0.9 `proc+opt_clean+stat`，未映射，仅作相对比较）

- **全设计（W=16 现行）**：**36,919 cells** / 9,242 dff / 17,976 mux / 399 mul；
  **memory bits 170,336**（= pbuf 131,072 + preamble_sync 39,264）；wire bits 679k；
  标称 RSTEN=1 变体 36,925（+6，可忽略）；
- **口径注**：proc 口径的 cell 计数**与位宽无关**（W16/W21 同数）——位宽收益只在
  wire bits / membits / 工艺映射后体现；W21→W16 存储 222,816 → 170,336 bits（−23.5%，线性）；
  存储未推 RAM（保守口径，pbuf 占 membits 77%，真 ASIC 推 SRAM 后大幅下降）；
- `preamble_sync` 30,039 cells（81% 逻辑）——**已知的面积之王**；
- ref（共享延迟线，候选）@W16 实测 **26,567 cells（−11.6%）/ `$mul` 28（−90%）/ membits 相同**（§14/§21）。

## 4. 已知限与"容许偏差"

1. **前 4 帧启动瞬态**（snr20）：统计时按稳态口径（跳过）或计入，**两口径均记录**；
2. **实现间 1 帧级差异**：不同实现原理（位宽路径/延迟结构/阈值敏感性）在**边缘帧**上
   可有 ±1 帧差——**不视为回归**（用户 2026-10-02 裁定）；
3. **6dB 档**：属"超规格压力测试"（低于标准灵敏度 ~14 dB），其数字**不作为验收线**，
   只作相对比较；
4. **mixdev1 口径**：归帧窗口必须与 `run_dual_mc` 一致（±1 帧级差异来自窗口选择）。

## 5. 变更流程（轻量）

```
改动 → 跑 §2 三流 + cocotb tb/rx_dual → 对照本表
  ≥ 基线（或 ±1 帧内）→ 合入，并更新本文档"版本锚点"
  低于基线 → 回退或记录原因
```
