# 19 发布说明 v1.1（2026-10-02）

> 对应 git tag **`v1.1`**。相对"设计基线 v1"（`docs/18`）的增量发布——
> 主题：**RX 双通道链路（rx_dual）的完成与固化**（共享前端 + 双执行段）。

## 1. 发布内容

### RTL（`rtl/`，结构见 `rtl/README.md`）

- **`rx_dual` 顶层**：共享前端 + 双通道执行段（A/B 各一套消旋/定界/解扩/解帧），
  单芯片双接收器（A/B 各覆盖一类设备参数）；
- **共享前端**：MF → 扫描同步 + 相位 latch（RST_EN 门控）→ `preamble_detect`
  → **`preamble_buf` v2** → `deinterleave`；
- **`preamble_buf` v2 = 1024 环 + BFP8 块浮点**（本版最大单项工作）：
  - 存储 131,072 → 20,784 bits（**−84%**）；逻辑 +579 cells——"579 个逻辑换 110k bit 存储"；
  - 量化保真 **41.7 dB**（与线性版逐样本对照，0 异常样本）；CFO 估计与线性版一致；
  - **指数双代机制**：解决"块级指数 vs 样本级存储"的环回绕代际错配（§38）；
  - **BLK 旋钮** 16/64/128 全部 RTL 验证（42.8 / 41.7 / 41.7 dB，与模型预测一致）；
- **同步器候选 Csq v3b**：`preamble_sync_csq.sv`——裁剪后 6,456 cells（**−23%** vs A16），
  边界回归打平（edge 94=94）；现役仍为 A16（`preamble_sync.sv`），切换评估见 `rtl/README.md`
  （**v1.2 已切 Csq——见 §5**）；
- **TX 链**：`tx_framer` / `oqpsk_modulator`（bit-true 回归）；
- **面积口径**（yosys 逻辑级，非签核）：全设计 **13,917 cells / 39,776 membits**（Csq 版）。

### 验证（发布门槛，全部通过）

- **边界回归 ALL PASS**：注入 8/8；edge A16 **94** / Csq **94**；snr20 **60/60**；
  snr6 **17/60**；mixdev1 FA **127–128** / FB **50**；
- **BFP/pbuf 专项**：`diag_pbuf_bfp.py`（41.7 dB、0 异常样本）；`run_blk_variants.py`（三档 BLK）；
- **模型侧**：`pytest model/tests` —— **8/8 passed**；
- **记录总表**：`model/out/dual_mc/rtl_area_notes.md`（§1–§40，设计与实验全日志）。

### 已知限制（承接 `docs/08` / `docs/14` / `docs/15` / `docs/16`）

- 自主触发（`preamble_detect` → `cfo_est` 片上闭环）未收敛——当前交付为外部参数通道；
- 6 dB 档虚警/门限：噪声底 CFAR 已入 `preamble_detect`（THR_SRC 参数），自适应接线待做；
- `preamble_buf` 的**转储读者**（射频驱动/外部存储接口）未定（§37 分析已备）；
- BFP 块长默认 64；深衰落/块内大动态信道的评估未展开。

## 2. 复现路径

```bash
# 场景重建（清理产物后的一键恢复；首次或数据缺失时跑）
python tb/rx_dual_mc/regen_scenes.py            # 重建 snr20/snr6/mixdev1/edge（同参数）
# RTL 系统级（VCS；sim_build 由脚本自建）
python tb/rx_dual_mc/build_variants.py          # 编译 A16/Csq 变体 bin
python tb/rx_dual_mc/run_boundary_regression.py # 边界回归（ALL PASS 判据）
python tb/rx_dual_mc/run_dual_mc.py             # 多设备蒙特卡洛
# pbuf / BFP 专项
python tb/rx_dual_mc/diag_pbuf_bfp.py           # BFP8 vs 线性对照（41.7 dB）
python tb/rx_dual_mc/run_blk_variants.py        # BLK 16/128 变体验证
# 模型侧
python -m pytest model/tests -q                 # 8/8
```
