> 2026-10-01。范围：本项目用语 —— 哪些沿用 802.15.4 标准（不另造）、
> 哪些是自造概念（先定义后使用）、哪些存在**同名不同义**或**同义不同名**。
> 目的：让"提升部分"（消旋体系、多通道并行、链路观测器）的命名与
> 标准不冲突、文档与 RTL 一致。

## 1. 沿用标准的术语（保持，不另造）

| 本项目 | 标准来源 | 说明 |
|---|---|---|
| 前导 preamble | 802.15.4 SHR 前 4 字节 | 本项目 8 符号、256 码片、2048 采样 |
| SFD | SHR 最后 1 字节 | 本项目"定界"用它定位帧起点 |
| PHR / PSDU / FCS | 802.15.4 帧结构 | 与标准同义 |
| 码片 chip / 符号 symbol | 802.15.4 | 1 符号 = 4 bit = 32 码片；2 Mchip/s，每码片 8 采样 |
| O-QPSK + 半正弦成形 | 802.15.4 | `half_sine_fir` 定点实现（Σh² = 16436） |
| 解扩 despreading | 通用 | 32 码片相关（`despreader`） |
| CFO / SFO | 通用 | 载波/采样频率偏差 |
| RSSI / LQI / ED / CCA | 802.15.4 MAC-PHY 接口 | **本项目未实现**；将来实现请用标准名（候选载体：`cfo_est` 的幅度 `aa`/`am`，见 §3.10） |

## 2. 自造概念的定义（"提升部分"用词，先定义后使用）

### 2.1 旋性 / 消旋
- **旋性（carrier rotation）**：收发载波频差在复基带上的表现 —— 复指数旋转。
  "**旋性差**"指两台设备（或两条通路）CFO 之差（dapping / 多通道语境用）。
- **消旋（derotation）**：对该旋转的复数补偿，载波域专名。
  RTL：`cfo_rot`，以及 `rx_chip_backend` 内的码片级复乘。
- 与"**校正**"区分：校正（correction）泛指 DC/IQ/定时等一切修正。
  建议不再用"矫正"（与"消旋"混用，见 §3.3）。

### 2.2 相位（本项目最重载的词，使用时必须带限定）
| 名称 | 含义 | 现用符号 |
|---|---|---|
| **载波相位增量** | 每（采样/码片）相位步进，抵消 CFO | `phase_inc`、`phase_inc_chip_a/b` |
| **帧起点载波相位** | 消旋器在帧起点的相位初值 | `phase_off` |
| **抽样相位** | 抽样时刻在 16 采样周期（=2 码片）内的位置 0..15 | `locked_phase`、`phase_out`、`phase_fix` |
| **对齐候选** | `cfo_est` 联合搜索的 8 个采样对齐之一 | `p_hat`（3 bit） |
| **相位命中 / 容限窗口** | 使解调可行的抽样相位集合（实测 [6..10]，宽 5 采样） | docs/16 §7.5 |

文档中一律写全称；RTL 符号改名放入"下次触碰该文件时顺带"（§4）。

### 2.3 抽取与去交错（deinterleave）
`deinterleave` 实际做两件事：**按抽样相位抽片（8:1 抽取）+ 偶奇分离（含 −j 旋转）**。
标准语境中 de-interleaving 多指交织编码 / 多相滤波，含义不同。
建议文档写作"**码片抽取（与去交错）**"；RTL 模块名保留。

### 2.4 定界（frame delimitation）与"同步"
- **定界**：SFD 相关定位帧起点（`sfd_detect` / `frame_start`）。
- "**同步**"一词过载（帧/载波/定时/位），建议**不单独使用**，
  必须加限定：帧定界、载波恢复、抽样定时。

### 2.5 链路状态体系（docs/16）
- **链路状态（link state）**：会被多帧复用的物理参数集（当前 = CFO）。
- **分辨单元（resolution cell）**：状态的容差宽度单元（`tol_hz`）。
- **状态表 / 匹配 / 发现 / 淘汰 / 热启动**：`patterns.py` 与观测器共用词。
- 旧词"**模式**"（docs/12/14/15、`patterns.py`）→ 文档层面统一为"链路状态"。

### 2.6 两级"锁定"（必须加限定）
- **扫描锁定（scan lock）**：`preamble_sync` 对抽样相位的判决（RTL 内）。
- **观测器 LOCK（link LOCK）**：后侧状态机对链路状态的判决（SEARCH/VERIFY/LOCK/LOST）。
层级不同，混用"锁定"会造成误读（实验讨论中已实际发生）。

### 2.7 服务窗口 / 服务调度（RRM 借用）
单消旋器 = 单一资源、多候选 = 待服务目标；"服务窗口" = 轮流独占期（docs/16 §7.2）。

### 2.8 dapping
正式名建议：**重叠帧分离（overlapping-frame separation）**；
"dapping"保留为内部昵称，首次出现处标注（docs/16 §8.4a）。

### 2.9 通道 / 信道 / 参数接口（三个不同东西）
| 词 | 含义 | 建议 |
|---|---|---|
| **信道** | 无线传播信道（AWGN/多径）；也指频点信道 n | 保持标准用法 |
| **通路（branch）** | `rx_dual` 的 A/B 两条旋性假设接收链路 | 建议"通路 A/B"，少用"通道" |
| **参数接口** | 上/下行参数通道（`ext_inc` 下行、I-13 缓冲上行） | 建议"参数接口" |

### 2.10 异常帧 / 前导缓冲（I-13）
`preamble_detect` 触发但未解析 ⇒ 异常帧；上报载体 = 前导码片缓冲。

## 4. 落地动作（低风险优先）

1. 本文档为术语基准；新 docstring / 提交信息按此用语（零改动，立即生效）；
2. `docs/06` 的"8 相位"修订（一处）；
3. README 增补本文链接；
4. RTL 符号改名（如 `phase_fix` → 抽样相位系列）**不做独立提交**，
   随下次触碰相应模块顺带进行；
5. "模式→链路状态"的文档级统一放到下次 docs 整理批次。
