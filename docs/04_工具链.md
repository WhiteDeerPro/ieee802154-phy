## VCS 环境变量（本机关键配置）

VCS 需要以下环境变量，已统一固化在 `tb/runutil.py` 顶部（`os.environ.setdefault`，可被外部覆盖）：

- `VCS_HOME=/opt/synopsys/vcs201809`
- `VCS_TARGET_ARCH=amd64`（**关键**：否则 VCS 会把 x86_64 误判为 32 位 `linux` 而找不到编译器）
- `SNPSLMD_LICENSE_FILE=/opt/synopsys/Synopsys.dat`
- `LM_LICENSE_FILE=/opt/synopsys/Synopsys.dat`

license server（`lmgrd`/`snpslmd`）在本机 27000 端口运行；本机主机名 `host-virtual-machine`
与网卡 MAC 均与 license 文件绑定一致，无需额外配置。

## 已确认不可用 / 不引入

- **Icarus Verilog（iverilog）**：本机未安装；仿真统一用 VCS（cocotb 的 `vcs` runner）。
- **GNU make**：不依赖。cocotb 2.x 使用 Python runner（`cocotb_tools.runner`），不需要 make。
- **Chisel / sbt**：不引入。RTL 用可综合 SystemVerilog 编写，VCS 完整支持。
- **cocotb 经典 Makefile flow**：跳过，统一用 Python runner 脚本。

## 仿真运行方式

每个验证点一个目录，内含 `{dut}.sv` + `test_*.py` + `run_*.py`：

```
uv run python run_xxx.py     # build（VCS）+ test（cocotb）一条龙，失败时 exit 1
```

`tb/runutil.py` 的 `run()` 默认 `get_runner(os.getenv("SIM", "vcs"))`，无需手动 export VCS 环境变量。

## cocotb 使用要点（本项目约定）

1. **读竞争**：`await RisingEdge(clk)` 后立即采样会读到旧值（与 `always_ff` 竞争）。
   采样前加 `await Timer(1, unit="ns")`，或等下一拍再采。
2. **黄金模型比对**：cocotb test 直接 `import model.phy_802154`，同进程生成期望向量，
   与 DUT 输出逐点比对 —— 这是本项目的核心验证手段（bit-true 比对）。
3. 冒烟测试样例见 `tb/smoke/`，新验证点照此结构复制。

## 波形调试（VCD / FSDB / Verdi / GTKWave）

**2026-09-29 排查记录 —— "Verdi 里看不到波形"的三个前置条件**（均非 fsdb 本身的问题）：

1. **license server 要先开**：`lmgrd`/`snpslmd` 不随开机自启。忘了开时 VCS 报
   `Cannot connect to the license server`、Verdi 报 `Could not checkout Verdi license`。
   用户态启动（无需 sudo）：
   ```bash
   /opt/synopsys/scl/v11.10/linux64/bin/lmgrd -c /opt/synopsys/Synopsys.dat -l /tmp/lmgrd.log
   /opt/synopsys/scl/v11.10/linux64/bin/lmstat -c /opt/synopsys/Synopsys.dat   # 查状态
   ```
2. **Verdi 需要显式 license 环境变量**：`tb/runutil.py` 只为 VCS 进程 setdefault 了
   `SNPSLMD_LICENSE_FILE`；裸 shell 跑 Verdi 要自己导出
   （`SNPSLMD_LICENSE_FILE=/opt/synopsys/Synopsys.dat`，另加 `VCS_HOME`）。
3. **nWave 窗口默认是空的**：fsdb 里有信号，但 Verdi 不会自动显示 ——
   需要拖信号或用 `-play` tcl 自动加载。本项目已提供 `tb/rtl_lab/verdi_signals.tcl`：
   ```bash
   python tb/rtl_lab/run.py --fsdb        # → sim_build/rtl_lab.fsdb
   verdi -ssf tb/rtl_lab/sim_build/rtl_lab.fsdb \
         -play tb/rtl_lab/verdi_signals.tcl -nologo
   ```

**FSDB 生成机制（cocotb 特有）**：cocotb 的 Python TB 里写不了 `$fsdbDumpfile`，需要
① 编译链接 Verdi PLI（`-P novas.tab pli.a`，见 `tb/rtl_lab/run.py` 的 `--fsdb`）；
② 在 SV 透传层用 `` `ifdef DUMP_FSDB `` 包住 dump 调用；
③ 运行时 `LD_LIBRARY_PATH` 指向 PLI 目录（加载 `libsscore_vcs201809.so`）。
参考实现：`tb/rtl_lab/`（fsdb 28 KB vs 同内容 VCD 8.2 MB）。其他观测点照此复制。

**波形存储约定（VCD 克制）**：日常回归不开波形；要看时优先 FSDB（小两个数量级）。
`cfo_corr_top.sv` 已有 `` `ifdef DUMP_VCD `` 条件 dump 的范例。

**GTKWave 备选**：`/usr/bin/gtkwave` 已装，可直接看 VCD/FST；
三个观测点已有 `gtkwave_signals.tcl`（`gtkwave -S tb/<点>/gtkwave_signals.tcl <wave>`）。
