# 偏移与对齐参数图谱（设计参考）

> 数字基带接收机里"偏移/对齐量"是普遍且必要的一类设计元素。本文按**时间尺度**
> 分类，给出机制选型依据，并索引本项目中的实例。最后专项讨论 `cref` 起始偏移
> 的性质（标称静态 vs 每包抖动）。
> 最后更新：2026-09-29

---

## 1. 为什么需要这个分类

偏移量散落在各模块里（相位累加器、采样相位选择、对齐点、起始偏移……），
如果只按"损伤 → 对策"组织文档（CFO/SFO/DC-IQ 各一节），容易忽略一个事实：

**不同时间尺度的偏移需要完全不同的机制**，混淆会导致设计错误：

- 把"每包"的当"静态"处理 → 帧间失配
- 把"累积"的当"每包"处理 → 帧内漂移无解
- 试图"修"瞬时的 → 白费力气与面积

## 2. 四类偏移（按时间尺度）

| 尺度 | 变化率 | 机制 | 项目实例 | 位置 |
|---|---|---|---|---|
| **① 结构/静态** | 永不（设计期定） | 参数 / 配置寄存器 | Q 路半码片偏移 | `phy_802154.py:146` |
| | | | **cref 起始偏移**（待加） | `cfo_est` |
| **② 每包** | 每帧一次 | 估计 + latch | `p_hat`（前导对齐点，8 选 1） | `cfo_est.sv:42` |
| | | | `phase_off`（帧起点相位 φ₀） | `cfo_est.sv:44` |
| | | | `lphase`（采样相位选择，16 选 1） | `preamble_sync.sv:173` |
| **③ 连续累积** | 每采样 / 每码片 | 累加器 + 环路 | `pacc`（消旋相位累加器） | `cfo_rot.sv` |
| | | | SFO 的逐码片采样位置偏移 | `run_sfo_fix.py:106` |
| **④ 瞬时** | 不可预测 | 无法修，靠裕量 | 相位噪声、时钟抖动 | 未建模（模拟侧） |

**③ 的典型形式**（`run_sfo_fix.py`，SFO 方案 [C]）：

```python
off = np.round(eps * 1e-6 * (m * 0.5e-6) * FS).astype(int)
#     ↑ 分数延迟 ε·t 累积        ↑ 取整到采样格  ↑ 帧内逐码片更新
# 采样位置 = 峰 + off[m]；RTL = 相位累加器 + 比较器（复用 8 相位结构，无需插值器）
```

这是"偏移驱动判决点"的标准范式：**累加 + 量化到已有相位格**。

## 3. 设计选型要点

1. **静态偏移要可配置**：它是"配置相关的常数"（随设计参数变），应做成参数/寄存器，
   不要硬编码字面量。
2. **每包偏移由同步器产出**：latch 后供本帧使用；跨帧不传递（帧到达相位随机）。
3. **累积偏移用累加器 + 环路**：注意位宽与回绕（相位自然回绕 2^N）。
4. **瞬时偏移不可修**：只影响裕量设计（如判决门限、保护间隔）。

## 4. 专项：`cref` 起始偏移会变吗？

**结论：会变，但要分两层——标称值静态、残余每包。**

### 4.1 背景

`cfo_est` 的参考序列 `c_ref_rom` 从码片 0 开始，要求收集窗起点与帧起点绝对对齐。
若 CFO 触发源是 `preamble_detect`（见 docs/08 I-6），其触发点相对帧起点有固定延迟。

### 4.2 标称值 ≈ 466 采样：静态 ✔

由结构决定（检测器窗填满深度 D+L=64 样本 × DEC=8，+ MF 群延迟 + 流水线）。
设计参数不变则不变 → **做成配置常数正确**。但注意它是"配置相关常数"：
改 L / DEC / MF 系数都会变。

### 4.3 残余抖动 ±18 采样（≈ ±2.25 码片）：每包 ✗

实测（20 帧 × 3 个 CFO 点）：

```
首触发偏移分布: 451~487 (均值 466, 标准差 ~10)
mod 8 分布均匀 → 不是下采样相位主导
```

来源（三者混合）：
- Λ 上升沿的坡度（窗逐渐覆盖前导）
- 噪声让"首次超阈"时刻抖动
- 帧到达相位影响首次覆盖的样本

**±18 > cref 对齐要求 ±8（1 码片）** → 单靠常数不够。

### 4.4 分层吸收（当前方案）

关键：`p_hat` 已在扫描 **8 个片内候选（±4 采样）**，因此

- **片内残余（±4 采样）** → p_hat 自动覆盖 ✔
- **片级错位（±2 片）** → cref 起始偏移参数负责（量化到片后，抖动表现为 1–2 片边界抖动）
- 净效果：估计质量略降，而非失效（介于 free-running 全崩与上帝视角 99% 之间）

### 4.5 更彻底的方案（备选）

**上升沿多点拟合**：Λ 从 0.2 升到 1.0 过程中取多点线性外推定位边沿，
精度可达 ±1 采样，远优于"首次超阈"的 ±18。代价是少量额外逻辑（或软件标定）。
