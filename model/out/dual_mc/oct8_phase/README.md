## 关键结论

- **资源**：第一刀（去乘法器阵列）−74%；第二刀（8→4 边形）边际仅 −4.7k；流水树 +2.8%。
- **判决正确性**：全部变体在单元压力台（15 万符号级）与模型**逐项 bit-exact**。
- **相位**（RTL 精扫 5 万/点）：四边形交叉区 (15°,17.5°)、45° 崩 1.89×（相位对齐偏好 → 不采用）；
  8 边形全相位无崩坏、波纹 14.3%（最差 φ=0°、最优 37.5°）。
- **整链传导**：五场景 + 200 帧扩样（snr20 200/200；snr6 58=58，字节流零差异）→ **零传导**。
- **流水判决树**：与组合版判决逐符号一致（恒定延迟 3 拍）；纯组合路径 46→16（−65%）；
  cells +2.8% —— 时序储备结构（参考 `ip/mcdf` 的 `mcdf_piro_encoder` 树）。
