# 链路综合测试报告：多设备 × 多 SNR × 通道参数替换（RTL 数模混合链路）

> 2026-10-02。配置：**扫描模式（参考配置 RSTEN=1 + ALIGN_GATE=1）**，`+PH=0 +NORMT=90`。
> 数据目录：`model/out/dual_mc/chain_report/`（主流）、`chain_report_eye/`（眼图流）。
> 分析脚本：`model/experiments/run_chain_report.py`。

## 1. 场景与变量

**主流（200 帧）**：12 帧模板循环 = 4 类设备 × 3 档 SNR（SNR 差由**发射幅度**实现，噪声底统一）：

| 设备 | CFO | 帧长 | SNR 档 |
|---|---|---|---|
| dev1 | +100 kHz | 20 B | 20 / 12 / 6 dB |
| dev2 | −100 kHz | 20 B | 20 / 12 / 6 dB |
| dev3 | +100 kHz | 64 B（重负载） | 20 / 12 / 6 dB |
| dev4 | +100 k→+125 kHz 线性漂移 | 20 B | 20 / 12 / 6 dB |

**通道参数替换（上位机简单算法示例）**：第 100 帧处把**通道 B 从 −100 kHz 改到 +125 kHz**
（"观测到漂移设备被 A 通道边缘化 → 让 B 通道转向漂移频段"，帧边界下发；I-10 协议雏形）。

**眼图流**：dev1 三连帧（20/12/6 dB），`+EYEDUMP` 抓 MF 采样级输出。

## 2. 结果

### 2.1 帧成功率（PER），替换前 → 后

| 设备 | 20 dB | 12 dB | 6 dB |
|---|---|---|---|
| dev1 | 8/9 → 8/8 | 8/8 → 9/9 | 3/8 → 5/8 |
| dev2 | 9/9 → **0/8** | 7/8 → **0/9** | 1/8 → 0/8 |
| dev3 | 8/9 → 7/8 | 8/8 → 9/9 | 1/8 → 2/8 |
| dev4 | 9/9 → 8/8 | 8/8 → 9/9 | 2/8 → 1/8 |

总成功 **130/200**；成功通道分布 A=98、B=32。
**要点**：① **20/12 dB 档各设备基本满收**（弱档损失集中在 6 dB）；② **替换机制精确**：dev2（−100 kHz）在替换后全灭（B 通道被转走）——代价可见；③ **dev4 的漂移**在 A（+100 kHz 固定）的相位宽容度内大多可收（20/12 dB 满收），B 追到 +125 kHz 的**边际收益有限**（6 dB 档 2→1）——"替换=零和"的直接演示。

### 2.2 输入/输出码流

**成功帧的载荷与发射 PSDU 逐字节完全一致：130/130 帧、4140/4140 字节，0 差异**（失败帧不计）。
→ 链路（调制→成形→信道→同步→消旋→解扩→解帧→CRC）在成功路径上**无损**，失败均以"帧级丢弃"呈现（CRC 兜底），不会输出错误载荷。

### 2.3 解扩相干和电平（"单信号扩频相干后的和"正确性）

A 通道、每点 = 32 片复和（符号相干累加），按 SNR 分档（`despread_levels.png`）：

| SNR | n | 中位 \|Σ32片\| | IQR |
|---|---|---|---|
| 20 dB | 2601 | 5.306e5 | (3.08, 8.09)e5 |
| 12 dB | 2602 | 2.263e5 | (1.39, 3.34)e5 |
| 6 dB | 2456 | 1.201e5 | (0.80, 1.73)e5 |

比值 20→12 dB ≈ 2.35（理论 2.51）、12→6 dB ≈ 1.88（理论 2.0）——**相干和电平随 SNR 正确缩放**；散点呈 16 向星形（码字方向），低 SNR 时径向散开（判决风险可见）。

### 2.4 眼图（MF 输出，I 分量，每码片 8 采样）

`eye_3snr.png`：中央采样位眼高（P90−P10）= **190200 / 83100 / 50659**（20/12/6 dB）——与 SNR 差（8 dB→×0.4、6 dB→×0.5）吻合。

## 3. 结论与讨论

1. **链路正确性达标**：成功帧载荷 100% 正确；失败集中在 6 dB 档（弱信号）。
2. **替换实验的价值与代价**：帧边界替换干净（机制层面精确到类）；但"单通道旋性"是**零和资源**——dev2 全灭换来 dev4 的有限提升。**上位机算法应带"候选集 + 观测回退"**（本次未含回退，见 I-10/I-17）。
3. **分层定位**：本链路属 **PHY（物理层）+ 少量 MAC（链路层）职责**（SFD 定界、白化、FCS/CRC 校验）。
   **CRC/FCS 应挂链路层（MAC 子层）**：它是"逐跳帧完整性"检查，不是网络层职责；网络层管地址/路由/转发。
   我们的 `rx_deframer` 的 CRC 等价于 MAC FCS 的简化实现，为上层（网络层）提供"干净帧"。

## 4. 局限

- 非理想效应覆盖 AWGN + CFO + 漂移 + 多设备；**多径 / I-Q 失衡 / SFO 未含**（见 model 侧对应实验报告）；
- 每格样本 8–9 帧（统计置信有限）；单次替换（无回退）；
- 尚未跑 cocotb 全量回归（见 docs/14 待办）。
